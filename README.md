# Assignment Showcase Portal

This project is a simple Assignment Showcase Portal created using HTML, CSS, and Iframe. It provides a centralized interface where users can access and view multiple web development assignments. The left panel contains assignment links, while the right panel displays the selected assignment inside an iframe without leaving the page.

## Features

* Centralized assignment dashboard
* Interactive navigation menu
* Embedded assignment preview using iframe
* Clean two-column layout
* Easy access to multiple projects
* Beginner-friendly design

## Technologies Used

* HTML
* CSS
* Iframe



## How It Works

* The left section contains buttons linking to different assignments.
* When a user clicks an assignment link, the webpage opens inside the iframe on the right side.
* Users can browse multiple projects without opening new tabs.
